# Корпоративный RAG-ассистент (Локальный, CPU)

Защищённый чат-бот на основе RAG (Retrieval-Augmented Generation), работающий **полностью локально** без передачи данных в интернет. Разработан для запуска на оборудовании без дискретной GPU (тестировалось на Intel Core i7-1185G7, 4 ядра / 8 потоков).

## 📋 Требования к системе

- **ОС:** Windows 10/11 (также работает на macOS/Linux)
- **Процессор:** 4+ ядра (рекомендуется 6+)
- **ОЗУ:** минимум 8 ГБ (рекомендуется 16 ГБ)
- **Диск:** ~6 ГБ свободного места
- **Python:** 3.10 или выше

## 🚀 Инструкция по запуску (Windows)

### Шаг 1. Установка Ollama и модели Mistral

1. Скачайте и установите **Ollama** с официального сайта: <https://ollama.com/download/windows>
   - После установки служба Ollama запустится автоматически в фоне (порт `11434`).
2. Откройте **новое** окно командной строки (cmd) и скачайте модель:
   ```cmd
   ollama pull mistral
   ```
   *Загрузка займёт время (~4 ГБ).*
3. Проверьте, что модель на месте:
   ```cmd
   ollama list
   ```
   В списке должна быть строка `mistral:latest`.

### Шаг 2. Клонирование репозитория и настройка окружения

1. Клонируйте репозиторий:
   ```cmd
   git clone https://github.com/ВАШ_ЛОГИН/corporate-rag-bot.git
   cd corporate-rag-bot
   ```
2. Создайте и активируйте виртуальное окружение:
   ```cmd
   python -m venv .venv
   .venv\Scripts\activate
   ```
3. Установите зависимости:
   ```cmd
   pip install -r requirements.txt
   ```
   > **Примечание:** `requirements.txt` содержит `torch` без индекса CUDA. На Windows pip по умолчанию установит CPU-версию — это и требуется.

### Шаг 3. Запуск Jupyter Notebook

1. Установите Jupyter (если ещё не установлен):
   ```cmd
   pip install notebook
   ```
2. Запустите ноутбук:
   ```cmd
   jupyter notebook
   ```
3. В открывшемся браузере откройте файл **`HW3_2.ipynb`**.

### Шаг 4. Выполнение ячеек

**Важно:** выполняйте ячейки строго по порядку.

1. **Ячейка 0** (установка пакетов): выполните её один раз. **После этого обязательно сделайте `Kernel → Restart`** в меню Jupyter.
2. **Ячейки 1–4** (загрузка данных и индексация): выполните их. Индексация займёт 2–5 минут на CPU.
   - Если папка `faiss_index/` уже есть в репозитории, ячейку 4 можно пропустить и сразу перейти к ячейке 5.
3. **Ячейки 5–8** (RAG-пайплайн и тесты): выполните их. Генерация ответа на CPU может занимать **30–90 секунд** — это нормально.
4. **Ячейка 8** (Gradio): после выполнения откройте ссылку `http://127.0.0.1:7860` в браузере для работы с интерфейсом.

## ⚠️ Известные ограничения (CPU-версия)

- **Скорость генерации:** Mistral 7B на i7-1185G7 выдаёт ~2–4 токена/сек. Ожидаемое время ответа — 30–90 секунд.
- **Память:** во время работы Mistral занимает ~4.5 ГБ ОЗУ. Рекомендуется закрыть лишние приложения.
- **Первый запуск:** первый запрос к LLM всегда самый долгий — модель загружается в память.

## 🛠 Устранение неполадок

- **`ConnectionError` при обращении к Ollama:** убедитесь, что Ollama запущена (иконка в трее) или выполните `ollama serve` в отдельном терминале.
- **`Torch not compiled with CUDA enabled`:** вы случайно установили версию с CUDA. Выполните `pip uninstall torch torchvision torchaudio -y`, затем `pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu` и перезапустите kernel.
- **Долгая работа:** это ограничение CPU. Для ускорения можно заменить модель в Ollama на `qwen2.5:3b` или `llama3.2:3b` (быстрее, но чуть менее точны).
- **Предупреждение о symlinks HuggingFace:** не ошибка, на работу не влияет.
